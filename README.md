# הפאזל 15

משחק שולחני בפייתון עם לוח 4×4, ערבוב שניתן לפתור, מונה מהלכים, שעון ועיצוב בעברית.

## הפעלה

נדרשים Python 3.10 ומעלה ו־Tkinter. בחלק מהפצות Linux יש להתקין את Tkinter בנפרד:

```bash
sudo apt install python3-tk
```

לאחר מכן מריצים מתיקיית הפרויקט:

```bash
python3 app.py
```

לחצו על אריח סמוך למשבצת הריקה או השתמשו במקשי החצים. „התחלה מחדש” מחזירה לאותו ערבוב, ו„משחק חדש” מגרילה לוח פתיר אחר.

## בדיקות

```bash
python3 -m unittest
```
